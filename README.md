# CLI Assistant 🤖

A modular command-line tool built with Python. It integrates Gemini API for AI interactions and includes a simple local note manager.

## Overview
I built this project to experiment with modular Python architecture, API integrations, and formatted terminal outputs.

## Key Features
- **Gemini AI Integration:** Terminal chat powered by Google's API.
- **Local Note Manager:** Quickly save and view notes from the CLI.
- **Rich Terminal UI:** Styled output using the `rich` library.
